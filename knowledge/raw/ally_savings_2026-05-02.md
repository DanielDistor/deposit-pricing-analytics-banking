- Direct deposit setup available (pre-filled form)

## Smart Savings Tools

Ally differentiates itself with savings automation tools:

### Savings Buckets
- Set money aside for specific goals — all in one account
- Like digital envelopes — stash cash for whatever you want
- Track progress toward goals while earning interest on total balance

### Boosters (Savings Automation)
1. **Recurring Transfers** — set it and forget it; move money into savings on a schedule
2. **Round Ups** — tracks spending accounts; rounds up transactions to nearest dollar; transfers when $5+ accrues
3. **Surprise Savings** — analyzes linked checking accounts for safe-to-save money; automatically transfers it to savings

*Research shows people saved on average 2x more when using Ally's smart savings tools.*
